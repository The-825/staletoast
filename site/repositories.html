This catalog is not a quality certification. Stars show audience attention only. A metadata or README screen is not a full appraisal.

What do the evidence depths mean?
  • README screened against a pinned revision: mechanisms were recorded from the README at one commit. It is not a code review.
  • Portable record, identity and provenance only: who and where the repository is, with no mechanism review.
  • README relevance check, awaiting appraisal: an automated check. Every mechanism stays unknown until a person appraises it.

Dates differ: the source snapshot is when the repository state was captured, the review or screen date is when the record was made, and the star date is when stars were counted.
